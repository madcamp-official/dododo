## 2. 제품 정책 질문

### 사용자 프로필

- 어떤 정보까지 사용자가 직접 입력하게 할 것인가?
- 저장·무시 기록으로 추정한 선호를 사용자에게 보여줄 것인가?
- 시간표와 성적 같은 민감 정보를 MVP에서 사용할 것인가?

### Opportunity

- 자격 정보가 없으면 추천할 것인가?
- 마감이 없는 공지를 언제 만료 처리할 것인가?
- 사용자가 저장한 순간 Event만 만들 것인가, Task도 만들 것인가?
- `dismissed` 항목을 언제 다시 추천할 수 있는가?

### LMS

- 수강 과목 목록은 사용자가 입력하는가, LMS에서 추출하는가?
- 시간이 없는 과제 마감은 당일 23:59로 가정할 것인가?
- 과제와 시험 외 수업 공지는 Note로 모두 저장할 것인가?
- 제출 완료를 LMS에서 확인할 것인가, 사용자가 완료 처리할 것인가?

### 화면 조언

- 어떤 앱과 화면을 관찰 대상에서 제외할 것인가?
- 화면 이미지를 외부 Vision 모델에 보낼 것인가?
- MVP는 수동 조언만 지원할 것인가?
- 몇 점 이상의 관련도에서 조언할 것인가?

### 알림

- Quiet Hours 기본값은 무엇인가?
- 마감이 임박하면 하루 최대 알림 수를 초과할 수 있는가?
- 마감 변경과 취소는 항상 즉시 알릴 것인가?

## 3. 기술 위험

| 위험 | 영향 | 기본 대응 |
|---|---|---|
| LMS 로그인·SSO 실패 | 자동 수집 불가 | HTML Fixture와 현재 페이지 가져오기 |
| 학교 사이트 구조 변경 | Collector 실패 | Selector 설정과 Fixture 데모 |
| LLM JSON 오류 | Context 저장 실패 | Schema 검증, 재시도, 오류 기록 |
| LLM 환각 | 잘못된 일정·Task | Evidence 필수, 낮은 확신도 확인 |
| 화면 권한 거부 | 조언 기능 불가 | Activity Fixture 지원 |
| CLI 종료 | 자동 수집·알림 중단 | `watch` 실행 상태 명시 |
| 잘못된 Task 병합 | Context 오염 | 자동 병합 기준, 이력, 사용자 확인 |
